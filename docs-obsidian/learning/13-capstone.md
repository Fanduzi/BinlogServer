# 第 13 节：Capstone（结业实战）

## 目标

把前面课程内容串成一次完整工程闭环：需求 -> 设计 -> 改动 -> 验证 -> 结论。

## 题目（固定）

为 `binlog_server` 做一次“可审计的小改动”，并提交完整证据链。

可选方向（任选其一）：

1. 文档增强
2. API 只读可观测增强
3. e2e 场景断言增强

## 交付物

1. 变更说明（What/Why）
2. 验证命令（至少 2 条）
3. 关键输出摘要
4. 风险与后续建议

## 完成标准

1. 交付物齐全
2. 验证链路可复现
3. 评审者可不追问复盘改动

## 5 分钟最小实操

1. 选一个小改动方向（文档/API/e2e 之一）。
2. 用模板写出“需求 -> 改动 -> 验证 -> 风险”四段。
3. 保证别人只看你的记录就能复盘，不需要追问背景。
