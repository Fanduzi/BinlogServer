# 学习章节实战检查清单

> 这不是考试评分表，而是项目学习的“防走偏清单”。

## 怎么用（轻量版）

1. 每章结束做一次 5~10 分钟检查。
2. 重点看“是否能复现”，不追求形式打分。
3. 做不到就记录卡点，回看章节，不强行硬闯。

## 每章通用三件事

1. 讲得清：能解释核心概念
2. 做得出：完成最小动手动作
3. 留得住：保留命令与关键输出

## 分章入口

- 第 0 节到第 12 节：按源码文档 `docs/learning/chapter-dod-matrix.md` 执行。
- 第 13 节：按 [[13-capstone]] 交付闭环证据。

## 结业建议

1. 00-12 每章至少留一条证据
2. 完成 [[13-capstone]]
3. 写一页收官笔记（掌握点、薄弱点、补强计划）
