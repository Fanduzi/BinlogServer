# Binlog Server v0.5.12 中文发布说明

> 对应版本：`v0.5.12`

发布日期：2026-10-03

这一补丁只修正随包指南。行为与 `v0.5.11` 相同。已发布的 v0.5.11 压缩包里仍是旧的中文 7.4，以及漏了 404 的英文句子。没有 schema migration，没有新的配置键，Console 也不能 adopt。

## 核心变化

- 英文 `docs/guide/admin/deployment.md` 第 8.4 节已经写了 `POST /api/tasks/{id}/adopt`、200、不返回密码、`STOPPED`、adopt 不会开始复制、adopt 之前的 400、最高封存或 `.open.e*` 分段的 `FILE_POS`，以及 start 204。现在补上：不是目录任务的 id 做 adopt，返回 404，正文是 `task not found`。已发布的 v0.5.11 linux amd64 包上的试用：`POST /api/tasks/99/adopt` 是 404 `task not found`，`backup_tasks` 仍是 0。
- 中文 7.4 现在写同一条 adopt 路径。遗留目录会列出。先 adopt，再 start。成功是 200，状态是 `STOPPED`。响应不返回密码。没传 start 时，保存的位点是最高分段源文件名和字节大小上的 `FILE_POS`。start 返回 204，写在同一目录。配了 `meta_dsn` 时，不是目录任务的目录返回 404 `task not found`。原来那句「这一行没有源库账号，不能启动」不再是唯一说明。
- 不需要 schema migration。没有新的配置键。Console 没有 adopt 按钮。行为与 `v0.5.11` 相同。
- Quick Start、落地页、部署文档、配置模板和 workers API 示例里的版本钉在 `v0.5.12`。

## 升级影响

- `v0.5.12` 不需要 schema migration。迁移仍只有 `000001_init_schema`。
- 配置键没有变化。`PRODUCTION=true` 仍要求非空 `--encryption-key`。
- 这一补丁只修正随包指南。行为与 `v0.5.11` 相同。已发布的 v0.5.11 压缩包里仍是旧的中文 7.4，以及漏了 404 的英文句子。
- Console 没有 adopt 按钮。
