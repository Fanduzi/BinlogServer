# Binlog Server v0.5.17 中文发布说明

> 对应版本：`v0.5.17`

发布日期：2026-10-04

`v0.5.17` 是 `v0.5.16` 的运维补丁。配了 `meta_dsn` 时，`GET /api/tasks/{id}/files` 和 Console 文件表按 standalone 磁盘扫描的同一顺序列出目录行。已发布的 v0.5.16 压缩包仍按 `sealed_at` 倒序列这些目录行。

## 核心变化

- 配了 `meta_dsn` 时，`GET /api/tasks/{id}/files` 和 Console 文件表按 standalone 磁盘扫描的同一顺序列出目录行：源文件序号升序；同一序号先封存名，再 `.open.e*` epoch。
- `limit` 保留序号最大的那些。没配 `meta_dsn` 的磁盘扫描没有变化。

## 升级影响

- `v0.5.17` 不需要 schema migration。迁移仍只有 `000001_init_schema`。
- 没有新的 API，没有新的配置键。`PRODUCTION=true` 仍要求非空 `--encryption-key`。30 秒阈值没有变化。
