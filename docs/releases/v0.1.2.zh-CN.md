# Binlog Server v0.1.2 中文发布说明

> 对应版本：`v0.1.2`

`v0.1.2` 聚焦前端运维管理体验升级：引入可复用的开发态 mock 基础设施，补齐更多集群异常场景，并将控制台重构为按工作区组织的导航与页面语义。

## 核心变化

- 新增前端开发态 mock（`VITE_USE_MOCK=true`），并与 Playwright E2E 共享同一套场景数据与处理逻辑。
- 扩展 mock 场景覆盖：`cluster-degraded`、`lease-risk`、`control-plane-down-worker-running` 等。
- 运维控制台按工作区拆分并支持深链：
  - `/#/overview`
  - `/#/tasks`
  - `/#/sources`
  - `/#/workers`
  - `/#/alerts`
- 将“运维筛选”收敛到任务/告警上下文，将“源库反查”收敛到源库上下文，减少单屏混放。
- 左侧导航升级为整列停靠式交互，折叠按钮下沉到左下，折叠态图标对齐修正。
- Lease 风险在 mock 场景下改为参考 `dashboard.generated_at`，减少本地时钟偏差导致的误判。

## 升级影响

- `v0.1.2` 无 schema 变更，不需要额外迁移步骤。
- 后端 API 契约无破坏性修改。
- 若你将前端静态资源与二进制分开发布，请同步更新 `v0.1.2` 的前端构建产物。

## 运维收益

- 以页面职责组织能力后，日常定位任务、源库、Worker、告警的路径更清晰。
- 前端联调与演示不再强依赖完整后端集群，开发效率提升。
- 本地和 CI 的异常态演练更接近真实生产语境。
