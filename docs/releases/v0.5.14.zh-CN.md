# Binlog Server v0.5.14 中文发布说明

> 对应版本：`v0.5.14`

发布日期：2026-10-03

`v0.5.14` 是 `v0.5.13` 的运维补丁。dump 文件头不是复制延迟。已发布的 v0.5.13 压缩包仍有这个误报。

## 核心变化

- 认领之后从最高分段末尾启动，源库已经在这个位点、没有新写入时，不再把 format description 的时间戳存成 `last_event_at`，也不再报 `DELAY_EXCEEDS_THRESHOLD`。仍在追位点的真实延迟继续用事件时间。
- 已经追上的 `RUNNING` 任务把 `delay_seconds` 以 JSON `0` 返回，Console 显示「0 秒」。还没有事件时间样本的任务仍然省略 `delay_seconds`，Console 仍可以显示「-- 秒」。

## 升级影响

- `v0.5.14` 不需要 schema migration。迁移仍只有 `000001_init_schema`。
- 配置键没有变化。`PRODUCTION=true` 仍要求非空 `--encryption-key`。30 秒阈值没有变化。
