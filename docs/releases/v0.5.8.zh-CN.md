# Binlog Server v0.5.8 中文发布说明

> 对应版本：`v0.5.8`

发布日期：2026-10-03

`v0.5.8` 是 `v0.5.7` 的运维补丁：bearer 鉴权打开时，浏览器可以直接打开嵌入 Console；管理指南写了用本地分段回放。

## 核心变化

- 配置了 `api.auth.enabled` 和 bearer token 时，浏览器打开 `/ui/` 不需要 `Authorization` 头。Console 能加载。设置框要求填写 bearer token，之后的 API 请求带 `Authorization: Bearer`。`/ui/*` 静态文件匿名。`/api/*`、`/metrics`、`/swagger/*` 不带凭证仍返回 401。`/healthz` 仍是 200。设置框里填的是 bearer token。配置键没有变化。
- 管理指南说明用 `mysqlbinlog` 或 `mariadb-binlog` 回放磁盘分段。路径是 `{data_dir}/{task_id}/mysql-bin.NNNNNN`。`.open.e<epoch>` 是普通 binlog 文件名上的后缀，工具按这个路径原样读取，不用改名。standalone 没配 `meta_dsn` 时，`GET /api/tasks/{id}/files` 是 `[]`，checkpoint 是 404，回放信磁盘。对象存储里只有封存且上传成功的文件。`v0.5.7` 的发布包没有 `docs/guide`。`v0.5.8` 的发布包带上了它，解压后就能看到回放这一节。
- Quick Start、落地页、部署文档和配置模板里的下载版本钉在 `v0.5.8`。

## 升级影响

- `v0.5.8` 不需要 schema migration。迁移仍只有 `000001_init_schema`。
- 配置键没有变化。`PRODUCTION=true` 仍要求非空 `--encryption-key`。
- bearer 鉴权打开时，`/ui/` 和静态资源不带凭证也能打开。在 Console 设置里粘贴 bearer token。`/api/*`、`/metrics`、`/swagger/*` 不带凭证仍是 401。`/healthz` 仍是 200。Swagger 仍然没有填写 token 的入口。
- 源库不可用时，回放 `{data_dir}/{task_id}/` 里的文件。standalone 没配 `meta_dsn` 时没有文件索引，也没有 checkpoint 行。正在写的分段不会出现在对象存储里。
