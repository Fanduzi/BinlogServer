# v0.1.0-alpha.2 Release Notes

发布日期建议：2026-02-19  
版本阶段：alpha（冻结版验收）

## 一句话摘要

完成 cluster 分离部署链路（control-plane/worker）与关键故障场景回归，补齐 worker 心跳与健康探针可观测能力，达到可灰度发布状态。

## 本版本主要内容

- Cluster 角色分离能力完善：
  - 支持 control-plane / worker / all-in-one 角色部署
  - worker 常驻接管 STARTING 任务，无需重启触发恢复
- Cluster 可观测性增强：
  - `/api/workers` 基于持久化心跳展示在线状态
  - worker-only 可配置独立 health probe 监听地址，提供 `/healthz` 与 `/readyz`
- Run 历史能力补齐：
  - `/api/tasks/{id}/runs` 返回来自 `task_runs` 的历史列表（支持 `limit`）
- E2E 场景扩展：
  - `smoke-cluster-roles`
  - `smoke-control-plane-failover`
  - `meta-failover` / `meta-failover-override`

## 已知限制（alpha 阶段）

- 集群高可用与严格文件语义已覆盖核心链路，但仍建议在预生产持续观察长时间运行稳定性。
- 默认告警/观测面仍偏轻量，生产建议配套外部日志聚合与监控系统。
