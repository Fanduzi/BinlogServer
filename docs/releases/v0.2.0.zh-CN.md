# Binlog Server v0.2.0 中文发布说明

> 对应版本：`v0.2.0`

`v0.2.0` 为前端控制台引入完整的国际化（i18n）支持，运维人员可在简体中文与英文之间切换界面语言，语言偏好持久化保存。

## 核心变化

- 引入 `vue-i18n@9`（Composition API 模式），覆盖全部 228 个用户可见字符串。
- 新增 `zh-CN` 和 `en` 两套 locale 文件，键名完全对称。
- 在「设置」对话框中新增语言切换器，偏好写入 `localStorage`，刷新后保留。
- 通过 `el-config-provider` 绑定响应式 locale，分页、日期选择器等 Element Plus 组件跟随语言实时切换。
- `formatTs` 时间戳格式化改为传入当前 locale，时间显示风格与界面语言一致。
- `README.md` 和 `README_ZH.md` 新增语言切换 badges。

## 升级影响

- `v0.2.0` 无 schema 变更，不需要额外迁移步骤。
- 后端 API 契约无破坏性修改。
- 若你将前端静态资源与二进制分开发布，请同步更新 `v0.2.0` 的前端构建产物。

## 运维收益

- 可在设置页一键切换控制台语言，适合中英文混合团队使用。
- 语言偏好跨会话保留，无需每次重新设置。
- 所有界面文本、表格列名、状态提示均已完整翻译。
