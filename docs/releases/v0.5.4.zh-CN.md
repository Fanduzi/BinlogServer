# Binlog Server v0.5.4 中文发布说明

> 对应版本：`v0.5.4`

发布日期：2026-09-07

`v0.5.4` 是 `v0.5.3` 的任务所有权和上传路径补丁。

## 核心变化

- 单机和集群走同一扇所有权门。单机进程注入进程内 lease 表，并用 `worker_id=standalone`，不再跳过 lease 检查。
- 任务进入 `FAILED` 时立刻释放 lease，别的 worker 不用等 TTL 就能 start。
- 进程启动和认领循环共用 `ClaimRunnableTasks`：自己闲着的任务、没人领的 `STARTING`、以及 lease 过期的 `RUNNING` / `LEASE_DEGRADED` / `RETRY_BACKOFF`。
- 第一次封盘上传先核对当前 lease，再走和 retry-upload 同一条 `ApplySealedUpload`。
- Dashboard 和 summary 对匹配任务只读一次，再在进程内分页。
- Quick Start、落地页和部署文档里的下载示例改为 `v0.5.4`。

## 升级影响

- `v0.5.4` 不需要 schema migration。
- 相对 `v0.5.3` 没有 API 契约变化。`GET /api/tasks` 仍是 `{items,total,limit,offset}`。
- 单机仍然不需要 `cluster.enabled` 或 metadata DSN。进程内 lease 表只活在当前进程里。
- 尽力上传语义不变：上传失败不打断拉流；手动重试仍走 `/api/tasks/{id}/files/retry-upload`。
