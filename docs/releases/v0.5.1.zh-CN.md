# Binlog Server v0.5.1 中文发布说明

> 对应版本：`v0.5.1`

发布日期：2026-08-30

`v0.5.1` 是 `v0.5.0` 的文档与证据补丁。复制、API 和调度行为没有变化。

## 核心变化

- Quick Start、落地页和部署文档里的下载示例改为 `v0.5.1`。`v0.5.0` 发完后这些入口仍在让值班去下 `v0.4.3`。
- 隔离环境跑过 `make e2e-scale`：1000 个控制面任务、100 路实时流全部位点前进且本地文件路径唯一。进程 RSS 约 112 MB，任务列表 p95 约 2 ms。100 个 dump 客户端共用一条 MySQL 5.7 fixture。
- 用 `config.production.example.yaml` 在本机核验了生产模板鉴权：无凭证访问 `/api/tasks` 和 `/metrics` 返回 401；`/healthz` 保持 200；未解析的 token 占位符会拒绝启动。

## 升级影响

- `v0.5.1` 不需要 schema migration。
- 相对 `v0.5.0` 没有 API 契约变化。如果是从 `v0.4.x` 升上来，`v0.5.0` 的 `GET /api/tasks` 分页变更仍然有效。
- 规模结果只是隔离 harness 证据，不是生产容量结论，也不是 100 个独立源集群。
