# Binlog Server v0.4.0 中文发布说明

> 对应版本：`v0.4.0`

`v0.4.0` 聚焦于管理页面的视觉质感优化：在不改变后端契约和核心操作流程的前提下，统一总览区、任务表格、详情抽屉与设置弹窗的层次、密度与可读性，让运维台在大样本场景下更稳、更易扫读。

## 核心变化

- 在 `frontend/src/App.vue` 中重做管理页 Hero、KPI 卡片与左侧导航的视觉基线：整体改为更克制的中性色表面、更紧凑的间距节奏，以及更清晰的 active / hover 状态。
- 优化 overview、worker、source 面板的信息分组与数字排版，关键统计值与标识字段更稳定，便于在大样本 mock 场景下快速识别集群状态。
- 调整任务表格的表头对比、行高密度与关键字段表现，并为 task name / delay / ID 等单元格补充语义类名，在不改变数据结构与操作入口的前提下提升可读性。
- 统一任务详情抽屉与设置弹窗的样式处理，并修正 Element Plus teleported 浮层根节点的样式命中方式，保证覆盖样式稳定生效。

## 升级影响

- `v0.4.0` 无 schema 变更，不需要额外迁移步骤。
- 后端 API 契约、任务生命周期与现有部署方式均无变更。
- 本次升级仅涉及前端管理页的视觉 polish 与可读性提升。

## 运维收益

- 总览区、任务状态与表格信息的层次更清晰，日常巡检时更容易快速定位异常与重点数据。
- 详情抽屉和设置弹窗的表面与动作区更统一，常规操作的阅读负担更低。
- 不影响现有 API 接入、任务控制行为与部署流程。
