# Binlog Server v0.4.1 中文发布说明

> 对应版本：`v0.4.1`

`v0.4.1` 是一次面向前端审计修复的补丁版本：重点解决管理台重构后带来的 UI 回归，恢复按钮与标签样式到 `main` 分支基线，并补强多工作区与 retry-upload 场景的 Playwright 回归覆盖。

## 核心变化

- 修复 `frontend/src/App.vue` 中任务详情抽屉的回归问题，保证任务详情重新拿到正确的 cluster 状态，并能在任务工作区稳定打开。
- 恢复前端按钮与标签到 `main` 分支的视觉基线，重新打通组件拆分后失效的 Element Plus 覆盖样式选择器。
- 更新 Playwright E2E 用例，使其覆盖当前的分视图工作区交互，包括导航、空态、告警、任务详情与 retry-upload，而不是旧的单页滚动假设。
- 去掉 retry-upload E2E 中复用旧 route session 的不稳定写法，改为在新的浏览器页面中完成第二阶段校验，减少偶发失败。

## 升级影响

- `v0.4.1` 无 schema 变更，不需要执行数据库迁移。
- 本次发布不包含后端 API 契约变更。
- 这是建立在 `v0.4.0` 之上的前端补丁版本，可直接升级。

## 运维收益

- 管理台中的操作按钮、状态标签和详情抽屉视觉表现重新一致，日常操作更稳定。
- 任务、Worker、源库、告警等分工作区流程与回归测试重新对齐，后续漂移风险更低。
- retry-upload 与任务详情交互在自动化验证和人工操作下都更可靠。
