# 架构概览

Binlog Server 是一个集中式的 MySQL binlog 备份服务，作为 MySQL 的"伪从库"持续拉取 binlog 并存储。

## 1. 高层架构

```

│                         Binlog Server 整体架构                                 │
└───────────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
┌───────────────────────────────────────────────────────────────────────────────┐
│用户 / 运维人员                                                                  │
│• API 调用：创建任务、启停、查询状态                                                │
│• Web UI：任务管理、状态监控                                                      │
│• /metrics：Prometheus 指标                                                     │
└───────────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
```

## 2. Standalone 模式架构

```
┌───────────────────────────────────────────────────────────────────────────────┐
│                       Standalone 模式（单机模式）                                │
└───────────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
┌───────────────────────────────────────────────────────────────────────────────┐
│┌─────────────────────────────────────────────────────────────────────────┐    │
││                            单进程                                        │    │
││                                                                         │    │
││    ┌────────┐      ┌───────────────┐      ┌────────────┐                │    │
││    │   API  │────→ │  Scheduler    │────→ │  Runner 1  │────┐           │    │
││    │ Server │      │               │      │            │    │           │    │
││    └────────┘      └───────────────┘      ├────────────┤    │           │    │
││                                           │  Runner 2  │────┤           │    │
││                                           ├────────────┤    │           │    │
││                                           │  ...       │────┘           │    │
││                                                                         │    │
││  MetaDSN 配置:                                                           │    │
││    • 不配置 MetaDSN → 内存存储，重启丢失                                    │    │
││    • 配置 MetaDSN   → MySQL 持久化，重启可恢复                              │    │
││                                                                         │    │
││  特点:                                                                   │    │
││    • 无集群 HA 功能（无 Worker 注册 / Claim Loop / Lease 续约）             │    │
││    • 适合开发/测试环境，或对可用性要求低的场景                                 │    │
│└─────────────────────────────────────────────────────────────────────────┘    │
│                                                                               │
│可选 MySQL 元数据库:                                                             │
│    • 配置 MetaDSN 后任务状态和 checkpoint 可持久化                                │
│    • 但仍无 Worker 注册、Claim Loop、Lease 续约等集群功能                          │
└───────────────────────────────────────────────────────────────────────────────┘
```

## 5. 任务状态机

```
┌───────────────────────────────────────────────────────────────────────────────┐
│                            任务状态机                                           │
└───────────────────────────────────────────────────────────────────────────────┘

                                  ┌───────────────────────────────────────┐
                                  │                                       │
                                  ▼        Recover                       │
  ┌────────┐    Start    ┌───────┴────────┐   ┌──────────┐               │
  │CREATED │────────────→│   STARTING      │──→│ RUNNING  │◄─────────────┤
  └────────┘              └───────┬────────┘   └────┬─────┘              │
       ▲                          │                 │                    │
       │                          │ Acquire Lease   │                    │
       │                          │ (cluster)       │ Renew Fail         │
       │                          ▼                 ▼                    │
       │                    ┌───────────┐   ┌─────────────┐              │
       │                    │  (直接     │   │  LEASE_     │──────────────┘
       │                    │  启动)     │   │  DEGRADED   │
       │                    └───────────┘   └──────┬──────┘
       │                                           │ Grace Exceeded
       │        Stop             ┌─────────────────┼─────────────────┐
       │   ┌─────────────────────┼─────────────────┼─────────────────┤───────┐
       │   │                     ▼                 ▼                 ▼       │
       └───┤   STOPPING      │    FAILED     │  REBUILDING  │ RETRY_BACKOFF  │
           └────────┬────────┴───────────────┴──────────────┴────────────────┘ 
                    │                                      │
                    │ Done                                 │ Retry
                    ▼                                      ▼
              ┌───────────┐                        ┌────────────┐
              │  STOPPED  │                        │  STARTING  │
              └───────────┘                        └────────────┘

状态说明:
• CREATED        - 任务已创建，等待启动
• STARTING       - 正在启动，等待 worker 认领或 runner ready
• RUNNING        - 正在拉取并持久化 binlog
• LEASE_DEGRADED - 续租失败但在 grace 窗口内
• REBUILDING_FILE - failover 后重建当前 binlog 文件
• RETRY_BACKOFF  - 因可重试错误进入退避等待
• FAILED         - 因不可恢复错误失败停止
• STOPPING       - 已收到停止请求，等待收敛
• STOPPED        - 执行路径已完全退出
```
