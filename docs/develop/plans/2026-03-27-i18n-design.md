# i18n 多语言支持设计文档

> 版本：v1.0
> 日期：2026-03-27
> 作者：Claude

## 1. 背景

Binlog Server 作为一个开源项目，需要支持国际化以便全球用户使用。当前状态：

- **前端**：Vue 3 + Element Plus 单页应用，约 175+ 硬编码中文字符串
- **文档**：用户指南等文档仅有中文版本

## 2. 目标

1. 前端支持中英文双语，可扩展其他语言
2. 用户面向的文档提供双语版本
3. 语言偏好持久化存储

## 3. 技术方案

### 3.1 前端 i18n

#### 3.1.1 技术选型

| 方案 | 优点 | 缺点 | 结论 |
|------|------|------|------|
| vue-i18n | Vue 官方标准，生态完善，支持复数/日期格式化 | 需要重构硬编码字符串 | **采用** |
| 简单 JSON + reactive | 轻量，实现快 | 缺少高级功能 | 不采用 |
| Element Plus 内置 locale | 只需配置 | 仅覆盖组件文本 | 作为补充 |

#### 3.1.2 目录结构

```
frontend/src/locales/
├── index.js           # i18n 实例配置
├── zh-CN.json         # 中文（简体）
└── en.json            # 英文
```

| 类别 | 数量 | Key 前缀 |
|------|------|----------|
| 应用标题/描述 | 8 | `app.*` |

**总计**：约 175+ 字符串

#### 3.1.4 Element Plus 国际化

Element Plus 内置组件需要配置 locale：

```javascript
import zhCn from 'element-plus/dist/locale/zh-cn.mjs'
import en from 'element-plus/dist/locale/en.mjs'

// 根据当前语言切换
const elementLocale = computed(() =>
  i18n.global.locale.value === 'zh-CN' ? zhCn : en
)
```

#### 3.1.5 语言切换 UI

在 Settings 对话框中添加语言选择器：

- 中文简体 (zh-CN)
- English (en)

语言偏好存储到 `localStorage`，key 为 `locale`。

### 3.2 文档 i18n

#### 3.2.1 命名规范

| 语言 | 文件名模式 | 示例 |
|------|-----------|------|
| 中文 | `{filename}.zh-CN.md` | `deployment.zh-CN.md` |
| 英文 | `{filename}.md` | `deployment.md` |

**理由**：
- 与现有 release notes 模式一致
- 英文作为国际通用语言使用无后缀文件名
- 文件同目录存放，便于维护

#### 3.2.2 文档分类

**需要翻译（23 文件）**：

| 优先级 | 目录 | 文件数 | 说明 |
|--------|------|--------|------|
| P0 | `docs/guide/README.md` | 1 | 学习入口 |
| P0 | `docs/guide/concepts/` | 6 | 概念文档 |
| P0 | `docs/guide/admin/` | 4 | 运维指南 |
| P1 | `docs/guide/dev/` | 7 | 开发指南 |
| P1 | `docs/guide/reference/` | 3 | 参考文档 |
| P0 | `docs/security.md` | 1 | 安全指南 |

**跳过翻译（44 文件）**：
- `docs/develop/` - 内部开发计划文档
- `internal/*/README.md` - 代码内部文档

#### 3.2.3 现有文档处理

1. 重命名现有中文文档为 `.zh-CN.md` 后缀
2. 创建对应的英文版本

## 4. 实施范围

### 4.1 前端

- 安装 vue-i18n 依赖
- 创建 locales 目录和翻译文件
- 修改 main.js 初始化 i18n
- 修改 App.vue 替换所有硬编码字符串
- 在设置对话框添加语言切换

### 4.2 文档

- 重命名现有中文文档
- 创建英文版本（可后续逐步完善）

## 5. 风险与约束

| 风险 | 缓解措施 |
|------|----------|
| 字符串遗漏 | 使用 grep 检查中文字符 |
| 翻译质量 | 使用专业术语，保持一致性 |
| 文档维护成本 | 使用相对路径，避免硬编码 |
