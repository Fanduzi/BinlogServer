之后 · 一个所有权 module

interface · 这个任务现在归谁跑？

内部：Epoch、宽限期、降级

Scheduler 只负责拉起执行。Runner 在 seal 前走同一条 seam。App 不再组装 VerifyLease。

问题

租约是一个概念，却摊成三个 interface 外加一个 App adapter。认领、恢复、Fail-safe Stop、seal 时验租分落在不同 module，所有权没有 locality。

改法

加深一个任务所有权 module，接口要小。Scheduler 与 Runner 穿过同一条 seam。App 只启动这个 module，不再重装租约。

  • · locality：#55 #56 #19 都在这里
  • · leverage：一条 seam，两处调用
  • · FAILED 目前不 Release 租约
  • · 测试不再用永远成功的 verifier
  • · 删掉 App 的 leaseVerifierFromStore

  • · 删掉重复的 interface
  • · 测试覆盖 seal-key == retry-key
